# 使用手册

> 返回：[README](../README.md) · 相关：[安装](installation.md) · [定制](customization.md)

## 1. 启动与基本操作

- 打开 WezTerm 即进入 Nushell（默认 shell）；
- 新窗口默认占活动屏幕 50%，居中显示；
- 从资源管理器右键 `Open WezTerm here`（需安装可选右键菜单）启动时，会直接落在该目录并同样居中；
- 关闭窗口/标签前请确认没有重要任务；`exit` 在 shell 正常退出时会关闭对应标签。

## 2. 标签页

| 操作                | 方式                                                 |
| ------------------- | ---------------------------------------------------- |
| 新建标签            | `Ctrl+T`，或标签栏"+"按钮左键                        |
| 新建指定 shell 标签 | `Ctrl+Shift+1/2/3`：WSL Ubuntu-24.04 / Kali / Arch   |
|                     | `Ctrl+Shift+4/5`：cmd / PowerShell 7                 |
| 关闭标签            | `Ctrl+W`                                             |
| 切换标签            | `Ctrl+1` … `Ctrl+8`                                  |
| 重命名标签          | `Ctrl+Shift+R`，输入新名称（静态标题显示为铅笔图标） |
| 标签导航器          | `F4`                                                 |
| 标签栏"+"右键       | 弹启动器（模糊搜索 + 启动菜单 + 域）                 |

标签标题会尽量显示：

- 手动设置的静态标题（铅笔图标）；
- 否则显示进程名；
- 前面带序号（`1:`、`2:`…）；
- 管理员权限进程会有标记；
- 未读/非活动标签使用不同配色。

## 3. 窗格（分屏）

| 操作         | 方式                                        |
| ------------ | ------------------------------------------- |
| 左右分屏     | `Leader`（`Ctrl+A`）然后 `h`                |
| 上下分屏     | `Leader` 然后 `v`                           |
| 关闭窗格     | `Leader` 然后 `q`                           |
| 在窗格间移动 | `Ctrl+方向键`                               |
| 调整窗格大小 | `Leader` `p` 后按 `h/j/k/l`，`Esc`/`q` 退出 |
| 复制模式     | `F1`（可滚动、搜索、选择）                  |

`Leader` 为 `Ctrl+A`，1 秒超时；不占用 Alt，避免与 Nushell/输入法快捷键冲突。

### 4.3 鼠标

- 左键拖选：选中文本；松开即复制；
- 右键：粘贴剪贴板；
- `Shift`+右键：复制选中内容；
- `Ctrl`+左键：打开链接；
- 鼠标中键：默认粘贴主选区（WezTerm 默认行为，未覆盖）。

## 5. 启动器与域

- `F3` 或标签栏"+"右键打开启动器；
- 内置启动项：PowerShell、Cmd、PowerShell v7、Nushell、WSL Ubuntu-24.04 / Kali / Arch；
- WSL 域声明在 `config/domains.lua`，可在多路复用场景选择。

## 6. 提示符阅读

典型提示符：

```
░▒▓ 󰍲   …\project     main     v1.80     1.2s   ❯
                                                           ⏱ 22:45
```

| 段落                | 含义                                                  |
| ------------------- | ----------------------------------------------------- |
| `░▒▓` + OS 图标     | 操作系统（Windows 图标）                              |
| `…\project`         | 当前目录（超过 3 层截断）                             |
| ` main`            | Git 分支                                              |
| `⇡1 ⇣2 ≠ ✘ » ! ? ⚑` | Git 状态：领先/落后/冲突/删除/重命名/修改/未跟踪/暂存 |
| 语言图标 + 版本     | Node/Bun/Rust/Go/C/C++/PHP/Python/Java/Docker         |
| ` 1.2s`            | 上一条命令耗时（>500ms 才显示）                       |
| ` 2`               | 后台任务数                                            |
| 右侧 `22:45`        | 当前时间（`right_format`）                            |
| `❯`                 | 成功字符；失败时变红；Nushell 的 vim 模式有对应符号   |

## 7. AI CLI 包装：`cc`

```nu
cc                   # 启动 Claude Code，标签名自动改为 "Claude"
cc --version         # 参数透传
cc --resume          # 继续会话
```

实现要点：

- `def --wrapped cc [...args: string]`：未知参数原样透传给 `claude`；
- 仅在检测到 `WEZTERM_PANE` 时改标签名，避免在其它终端报错；
- 需要 `claude` 与 `wezterm` 在 PATH。

## 8. Windows 11 一级右键菜单

安装可选组件后：

- 资源管理器空白处右键 → 一级菜单直接出现 **Open WezTerm here**；
- 文件夹上右键 → 同样出现；
- 点击后在目标目录打开 WezTerm + Nushell；
- 不需要点"显示更多选项"；
- 旧经典入口仍保留在"显示更多选项"里作为回退。

## 9. 常用工作流

### 9.1 在项目目录直接开终端

安装右键菜单后：资源管理器进入项目 → 空白处右键 → `Open WezTerm here`。

### 9.2 分屏 + WSL

```text
Leader h        # 左右分屏
Ctrl+Shift+1    # 新标签里开 WSL
```

### 9.3 查看 Git 状态

进入任意 Git 仓库目录，Starship 自动显示分支与状态符号，不需要手动 `git status`。

### 9.4 长任务计时

命令执行超过 500ms 时，提示符会显示耗时，例如 ` 3.4s`。

### 9.5 复制远端输出

- 左键拖选 → 松开自动复制；
- 或 `F1` 进复制模式，支持键盘滚动/搜索。

## 10. 配置修改与生效

| 修改内容                               | 生效方式                            |
| -------------------------------------- | ----------------------------------- |
| WezTerm 入口 `wezterm.lua`             | 自动热重载                          |
| WezTerm 子模块（config/events/colors） | 保存后若不生效，`Ctrl+Shift+Alt+R`  |
| Nushell `config.nu`                    | 新开标签/窗口，或执行 `source` 重载 |
| Starship `starship.toml`               | 下一条提示符立即生效                |
| 补全文件                               | 新开 Nushell                        |
| 右键菜单 JSON                          | 重启资源管理器                      |

## 11. 小技巧

- `Ctrl+Shift+L` 打开 WezTerm 调试面板（也可用 `F12`）；
- `F11` 全屏；
- `Leader f` 后 `j/k` 缩放字号，`r` 重置；
- 在资源管理器里选中文件夹按 `Shift+F10` 也能弹出右键菜单（键盘操作）；
- 提示符图标显示为方块时，优先检查 Nerd Font 是否安装。
